HerNet packages

Patched dynamic modules for signed official NGINX mainline binaries. Debian bookworm/trixie and Ubuntu jammy/noble/resolute, amd64. Automatically follows official mainline releases newer than 1.31.6. A target is published only when its exact official package is available and its module tests pass.

Install

First configure the official NGINX mainline repository. Verify fingerprint FC18C0BCE21885538FFA4010B5687B8D0182B312 before trusting it.

curl -fsS https://hernet-pkgs.palve.moe/hernet-pkgs.gpg \
  | sudo tee /usr/share/keyrings/hernet-pkgs.gpg >/dev/null
. /etc/os-release
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/hernet-pkgs.gpg] https://hernet-pkgs.palve.moe/mainline/$ID $VERSION_CODENAME main" \
  | sudo tee /etc/apt/sources.list.d/hernet-pkgs.list
sudo apt update
# Choose modules independently; Lua installs NDK and libraries as dependencies.
sudo apt install nginx-module-lua-ha nginx-module-http-njs-ha
# Full set:
sudo apt install nginx-module-ndk-ha nginx-module-lua-ha \
  nginx-module-fancyindex-ha nginx-module-http-geoip2-ha \
  nginx-module-stream-geoip2-ha nginx-module-vts-ha \
  nginx-module-http-njs-ha nginx-module-stream-njs-ha

Modules reside in /usr/lib/nginx/ha-modules/<exact-nginx-package-version>/hernet-1.0.3-r1/. Configure explicit load_module paths. Upgrade NGINX and its modules together; packages enforce the exact official NGINX package version.

RTMP / HLS and official stream

Usage and separate configuration. Both packages bind the exact official NGINX version. Configuration is not bundled in either DEB. Stream forwards RTSP over TCP; it does not convert RTSP into HLS.
